## 코드와 영향 지도

기존 `execution/tablet_code_map_audit.py`로 원본 추적 파일 1,925개와 Python 파일
1,007개를 분석했다. Python 구문 분석 문제는 0건이다. 이 지도는 정적 import
관계이며 동적 실행 전체를 증명하지 않는다. 기존 Graphify 계약 검사는 19개 파일,
275개 계약, 42개 실행 테스트 노드를 확인했고 누락·실패가 없었다.

화면 흐름은 `navigateShortcut/openTarget/dock click -> selectCategory ->
showManagedTarget -> syncAppDockSelection`이다. 숨김·뒤로·접기도 같은 선택
동기화를 사용한다. 직접 상단 탭 클릭은 기존 패널 핸들러 실행 후 microtask에서
동기화한다. 새 polling, MutationObserver, 외부 요청, 학습 작업을 추가하지 않았다.

반복 렌더 1,000회에서 링크 객체 재사용, DOM 노드 추가 0개, 각 링크의 click
핸들러 1개를 검사했다. 이는 작업량의 상한 검사이며 실제 태블릿 지연시간이나
메모리 사용량의 측정 결과는 아니다.

## 계보와 변조 방어

`.github/tablet-autonomy/dock_state_successor_v878.json`은 기준 main과 소스 후보의
정확한 변경 파일 집합, 이전·이후 SHA-256을 독립 상수와 대조한다. 이후 등록된
검증 파일의 현재 해시는 원래 후보 행과 별도로 고정한다. 역사 V652의 승인 해시는
변경하지 않았다. HEAD 조상 관계, 현재 파일, 심볼릭 링크 여부와 false 배포·기기
플래그를 매번 확인한다. 불변 Git 객체 증거만 캐시하고 현재 파일 검증은 캐시하지 않는다.

기준 main 이전부터 있던 다른 변경, 알 수 없는 경로, HEAD 이외의 비교, 소스·테스트
변조, 위조 플래그, 분기된 조상 관계는 위임하지 않는다. V426/V477/V479/V566
검사도 유지했으며 해당 대표 검사 11/11이 통과했다. V652/V653/V657/V658 관련
176개 검사도 통과했다. 새로운 최고 세대 계약은 V664의 규칙과 감시 범위를 유지한다.

전체 root 검사에서 새 최고 세대 loader 추가로 루트 항목 수가 984에서 985로
증가한 것이 확인됐다. 관련 기존 `test_tablet_app_dock_v275.py`를
`execution/tests/`로 이동해 새 loader에서 계속 실행한다. 테스트 assertion은
그대로 두고 ROOT 계산 한 줄만 변경했다. 원본 후보의 테스트와 이 한 줄 차이만
있는지 별도로 검증하며, 기존 루트 수 제한은 수정하지 않았다.

점수는 실제 검사 통과율로만 표현한다. 성능 개선율·전체 품질 점수는 추정하지 않는다.

| 실제 Lenovo 렌더·렉·메모리·터치 | 미검증; 설치·배포 승인 근거로 사용하지 않음 |

로컬 테스트는 임시 디렉터리를 저장소 밖에 둔다. 제한된 환경에서 `/tmp`가 쓰기
불가하면 Python이 현재 저장소를 임시 경로로 선택할 수 있다. 이 경우 임시 fixture가
상위 Git 변경을 잘못 읽거나 fault-lab 복사 대상 안에 다시 생성될 수 있다. 검증
실행 시 `TMPDIR`을 쓰기 가능한 저장소 밖 경로로 지정한다. 이를 제품 오류나
CI 통과로 오인하지 않는다. 원격 CI는 해당 실행 환경에서 다시 확인한다.

## 참고 도구·공식 자료

- MDN [addEventListener](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener):
  익명 핸들러를 새로 만들 때의 중복 등록 위험을 참고해 반복 호출에서 실제 핸들러
  개수를 검사했다. 외부 소스를 복제하거나 의존성을 추가하지 않았다.
- Playwright [Trace Viewer](https://playwright.dev/docs/trace-viewer):
  향후 로컬 렌더 검증의 DOM snapshot/trace 분석 후보다. 도입·브라우저 실행·성능
  개선을 주장하지 않는다. 호스팅된 브라우저나 외부 trace 업로드를 사용하지 않았다.
- 기존 GitHub 회귀·Graphify·무결성·아키텍처 도구를 재사용했다. 새 외부 앱·런타임
  의존성·클라우드 학습·저장소를 추가하지 않았다.

병합은 최신 후보의 필수 CI를 근거로 판단한다. 물리 태블릿 검증과 자동학습·등급
캘리브레이션의 검증 상태는 이 코드 복구와 별개로 유지한다.
