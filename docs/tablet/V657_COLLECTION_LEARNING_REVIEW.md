# V657 수집 대기·로컬 학습 부하 재검토

2026-10-24 KST. PR #802의 V652–656 수정본에 대한 후속 검토다. 새 브랜치를 만들지 않는다.
기능 코드 작성, 저장소 테스트, CI, 실제 태블릿 설치·재부팅·터치·렉 측정은 각각 별도 증거다.

## 재현한 결함과 수정

- 기존 단일 감시 루프는 정상 상태에서도 매분 Query/Job `status()`를 호출하여 라벨 파일을 다시 읽었다. 정상 학습 상태는 같은 실행 SHA에서만 최대 15분 재사용한다. 감시 15회에 대한 라벨 조회 호출은 15회에서 1회로 줄고 소스/HTTP 실행 SHA 검사는 매번 유지한다. 이는 결정적 호출 수 측정이며 실물 CPU/렉 개선율이 아니다. `auto-status`와 `tablet-learn`은 최신 라벨을 직접 읽는다.
- 학습 오류 재시도는 매분에서 5분 간격으로 바꾼다. 런타임 일시 중단이 최근 학습 확인 시각을 지워 복구 직후 불필요한 재학습 검사를 일으키지 않도록 마지막 관측을 보존한다. 실제 학습은 기존 6시간 주기·정답 수·클래스·시간순 검증·기존 모델 보호 기준을 유지한다. 상태 재사용 시 원 관측 시각과 `learning_status_cached`를 기록한다.
- 공식계정 검색이 `Retry-After: 172800`을 24시간으로 줄이고 HTTP 날짜형을 무시하던 문제를 수정한다. 48/72시간 대기도 재실행 후 유지하며 다른 제공처의 수집은 기존 예산 안에서 계속한다. 요청·이미지 상한은 올리지 않는다.
- 현재 PR의 CodeQL 집계 실패를 확인했다. 미리보기 Content-Type을 상수 표에서만 선택하고, CSP 테스트의 SCRIPT/SRC 대소문자 누락과 테스트의 URL 부분문자열 검사를 고쳤다. CodeQL 재실행 결과 전에는 보안 PASS를 주장하지 않는다. 테스트 경고와 실제 운영 취약점은 구분한다.

## 이번에 유지·재검사하는 사용자 요구

국가별 전체/한판/일판/미판/중판 통합 탐색, CN-S/CN-T 구분, 게임별 카드·BOX·로컬 이미지 연결,
정확한 식별번호에 의한 누락 메타데이터 보완, 읽기 해상도·픽셀을 보존하는 무손실 저장은 기존 V652–656 코드와 회귀검사를 재사용한다.
이미지 상한은 6시간마다 36장/최근 24시간 144장, 제공처당 24장/일이다. 상한은 실제 수집량이나 제공처가 보장한 안전 한도가 아니다.
실제 차단·요청 실패·자료 결손·언어별 미지원은 결손으로 남기며 다른 국가 카드로 채우지 않는다.
포켓몬 정확 ID 메타데이터 보완을 모든 게임의 자동 완성이라고 표현하지 않는다.

학습은 실제 수집 관측과 검증된 정답을 계속 누적하며 중복 관측·시점 불명 과거 자료를 학습량에 부풀려 넣지 않는다.
Query/Job 모델은 수집 우선순위 보조용이다. 카드 이미지 인식·등급 모델의 자동 재학습이나 중국판/추가 게임 전체 지원 완료를 의미하지 않는다.
학습 데이터 부족·양/음성 불균형·시간 분할 부족은 `training_readiness`로 계속 표시한다.
기존 모델과 실제 사진/라벨은 로컬에 유지한다. 웹 자료로 실행 코드를 자가작성하지 않는다.

## 적용 경로와 실제 확인

설정 명령과 요구사항 전체 대조는 [V656_TERMUX_AUTOMATION.md](V656_TERMUX_AUTOMATION.md)를 따른다.
일반 main 업데이트로 미병합 PR이 설치되지 않는다. 병합 전에는 main을 변경하거나 태블릿 강제 초기화하지 않는다.
병합된 코드가 검증된 기존 보존 업데이터로 설치된 다음 `bash main auto-install`, `bash main auto-status`를 실행한다.
현재 작업 환경에는 사용자 태블릿의 직접 접속·설치·재부팅·화면/성능 로그가 없다. 그 항목은 미확인으로 유지한다.
