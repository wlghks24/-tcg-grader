## 새로운 외부 2차 백업 검사 명령

코드가 정식 main에 병합된 이후, **기존 운영 환경에서 복구 가능한 외장 매체 사본이 있을 때에만** 실행한다.

```sh
python -m execution.tablet_secondary_backup_audit \
  --root "$HOME/-tcg-grader" \
  --backup "$HOME/tcg-preserve-20261112-232258" \
  --external-copy "/실제별도파일시스템/복사된-백업" \
  --extra-dir "local-extra-20261112-234739" \
  --require-copy-verified
```

기존 V1012 원본 무결성 검사와 2차 사본 JSON·Git bundle·비공개 파일 해시를 비교한다. 외부 사본의 SHA256SUMS/manifest/bundle이 독립적으로 유효하고 **원본과 동일한 해시**일 때만 2차 *파일시스템 사본*이 검증된다. 단순 경로 차이가 아니라 파일시스템 ID도 달라야 한다. 그러나 물리적 별도 장치 소유/안전한 외장 보관, 데이터 저장 중지·복원 시운전은 이 도구로 자동 증명할 수 없다.

`--require-install-ready`는 **언제나 종료 코드 2**, `install_allowed=false`이다. 본 기능은 백업 보완 검사일 뿐 설치/삭제·파일 변경·학습 수행 명령이 아니다.
