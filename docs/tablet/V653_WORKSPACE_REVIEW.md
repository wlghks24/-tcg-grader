## 검토와 실제 수정

UI, 행사 수집, 이미지 식별을 나누어 독립적으로 분석하고 root가 통합했다.
검토 과정에서 발견한 아래 문제를 재현했다. 검토 인원수나 가상의 품질 점수를 실행 증거로 사용하지 않는다.

| 영역 | 확인된 문제 | 변경 |
|---|---|---|
| 탐색 UI | 여러 CSS의 우선순위 충돌, 큰 메뉴와 중복 안내 | 명시적인 V653 범위에서 차분한 초록·종이색 디자인, 태블릿 4열/휴대폰 2열 탐색, 상세 가시성 관리 유지 |
| 카드·BOX | 이미지 상세와 시세 화면이 분리됨 | 이미지와 메타데이터 요약, 기존 엄격한 시세 대조로 연결. BOX는 상품목록 수동 검토로 분리 |
| 중국판 | 시세 상세 파서가 중국판 행을 제외 | CN/S/T 지역을 표시하되 간체·번체를 섞지 않음. 중국판 사진 등급 지원을 새로 활성화하지 않음 |
| 세대·등급 | 숫자만 표시하면 미확인 정보가 사실로 오인될 위험 | 세대는 출처·자료일·세트·검토 근거가 있을 때만 표시. 예상등급은 실물 앞·뒷면 측정이 필요함을 명시 |
