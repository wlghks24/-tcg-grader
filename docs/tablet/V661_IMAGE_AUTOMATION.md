# V661 기존 6시간 감시와 이미지 후보 학습 연결

이 변경은 별도 타이머 없이 기존 auto-install 단일 감시 루프의 학습 확인을 사용한다.
`tablet_local_learning.run(train=True)`가 Query/Job 이후 이미지 학습 어댑터를 호출한다.
일반 상태 조회는 이미지 디코딩 없이 마지막 보고서만 읽는다.

기존 main에 아직 병합되지 않은 PR 수정본이다. 실제 태블릿 설치·재부팅·성능을 뜻하지 않는다.
수정본이 검증된 보존 업데이터로 설치된 후 프로젝트 폴더에서:

```
bash main auto-install
bash main auto-status
bash main tablet-learn
```

이미지 입력은 GRADE_TRAINING_INBOX/verified_raw_photos.json 이다.
V660_IMAGE_TRAINING_CHALLENGER.md의 로컬 검토 schema를 사용하며 이미지 경로는
GRADE_TRAINING_INBOX 아래 상대 경로다. 데이터가 없으면 WAITING_FOR_REVIEWED_RAW_PHOTOS를 표시한다.
공식 인증 결과와 원본 사진을 연결한 검토 데이터가 없는데 자동으로 정답을 추정해 채우지 않는다.
기존 웹 사진 수집과 Query/Job 데이터 누적은 이 대기와 별개로 계속한다.

새 특징 schema=2는 8×8 문맥 RGB와 원본 해상도 4×4 영역의 경계·밝기·밝은 픽셀 분포를 쓴다.
영역 특징은 전체 이미지를 8×8로 줄여 얻지 않는다. 이 특징 자체가 결함 위치·등급 정확도 입증은 아니다.
기존 특징 보관함은 삭제하지 않고 admitted_features_v2.json에 별도 누적한다.
사진당 8MB/2천만 픽셀, 회당 신규16장/128MB/입력시간8초, 학습30초를 제한한다.
자료 수·클래스·독립 평가 자료가 부족하면 부족 사유와 남은 수량을 기록한다.

후보는 학습 데이터에서만 학습한다. 검증과 별도 holdout 양쪽에서 기존 보조 챔피언 또는
학습 데이터의 빈도/평균 기준보다 개선해야 보조 챔피언을 교체한다.
등급은 MAE≤0.5, 개선≥0.02, 과대등급률≤10% 및 기존보다 악화 없음, 편향 절댓값≤0.25다.
인식은 정확도≥90%, 개선≥1%p, Brier≤0.15 및 기존보다 악화 없음, ECE≤0.1이다.
기존 보조 모델은 last-good으로 원자 저장하며 동일 기준을 다시 통과하는 경우에만 복구한다.
이 수치는 초기 보수적 코드 기준이지 측정된 제품 성능이 아니다.

보조 모델 저장 위치: ~/.local/state/tcg-grader/image-learning/.
실시간 OCR·PSA/BGS 등급 보정 및 기존 실사용 가중치를 덮어쓰지 않는다.
검증된 데이터가 없는 현재 환경에서 전체 실사용 등급 모델의 자동 교체 완료를 주장하지 않는다.
별도의 inference/추론 UI 소비 경로와 실물 정답 평가·배포 승인 증거는 후속 검증 대상이다.
태블릿 직접 접속이 없는 환경에서는 설치·최초 실행·실제 성능을 확인할 수 없다.

루트 파일 수는 기존 한도 유지: 위치 의존성이 없는 V619 테스트 로더를 execution/tests로
바이트 그대로 옮기고 V661 루트 검사에서 동일 ImproverTests를 명시적으로 실행한다.
과거 source pin은 V661의 정확한 기준/후보 커밋·SHA256으로 이어서 검증한다.

자원 사전 확인: 여유 저장공간 256MB, 사용 가능 메모리 512MB, CPU 부하를 확인하며 부족/측정 불가 시 선택 학습을 DEFERRED_RESOURCE_BUDGET으로 보류한다. 이 조건으로 기존 수집 모델을 중단하지 않는다. 로컬 합성 이미지 특징 추출 측정은 1024×1024 약0.029초, 4400×4400 약0.656초, 측정 프로세스 최대 RSS 약244MB였다. 태블릿 측정값이나 실제 결함 정확도가 아니다.
