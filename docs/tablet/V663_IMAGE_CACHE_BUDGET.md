# V663 누적 특징 보관함의 실제 크기와 읽기 한도

4천 행 × 288개 특징을 원자 JSON 저장 형식(indent=2)으로 직렬화하면 테스트 데이터에서
약 33.8MB가 된다. 기존 25MB 읽기 한도는 정상 보관함을 다음 주기에 거부할 수 있었다.
최대 4천 행·특징 288개 제한은 유지하면서 특징 보관함의 명시적 읽기 상한을 64MB로 맞춘다.

회귀검사는 실제 25MB 초과 파일을 저장하고 다음 학습 주기에 읽히는지 확인한다.
이 테스트의 모의 특징값은 읽기 경계 시험용이며 실제 학습 정답이나 정확도 증거가 아니다.
4001행은 계속 거부한다. 새 사진은 열린 파일의 크기·타입과 실제 읽은 바이트를 함께 검사하여
사전 stat 이후 파일이 커져도 사진당 8MB 한도를 우회하지 못한다.

기존 6시간 루프, 새 사진 16개/128MB/입력8초, 학습30초, 자원 여유 확인,
실제 사진 검토·공식 인증·중복 제외·holdout·보조 모델 교체/복구 기준은 유지한다.
실제 태블릿 설치나 전체 등급 모델의 실물 정확도 완료를 의미하지 않는다.

루트 한도를 유지하기 위해 위치 의존성이 없는 포켓몬 공식 링크 별칭 회귀검사를
바이트 그대로 execution/tests로 옮기고 V663 루트 검사에서 같은 4개 테스트를 실행한다.
