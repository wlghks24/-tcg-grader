# V654 누락 카드정보의 독립 재확인

수집 페이지가 진행된 뒤 예전에 저장된 카드의 세트정보 보완이 실패하면,
그 페이지를 다시 만날 때까지 자동 보완이 지연되는 경로를 확인했다.
TCGdex 목록/상세의 구분은 공식 문서 https://tcgdex.dev/rest/cards 에서 확인했다.
SDK를 추가하거나 외부 소스를 복사하지 않고 기존 상세 요청·저장 검증을 재사용한다.

자동 이미지 수집 주기 시작 시 기존 개인 이미지의 누락 세트정보를 최대 4건 재확인한다.
기존 요청·바이트·실행시간 예산과 출처별 403/429 대기를 공유한다.
실패는 재시작 후에도 6시간 대기하며, 대기 중인 카드가 다른 카드를 밀어내지 않는다.
같은 실행의 일반 수집 페이지가 동일한 실패 요청을 다시 보내지 않는다.
완료·시도·미완료 수는 자동수집 결과의 metadata_repair_* 필드에 남는다.

기존 로컬 파일, 자동수집 출처, 카드 ID, 언어, 지역이 모두 맞아야 재확인한다.
수동·삭제·타지역 이미지는 대상이 아니다. 이미지 재다운로드나 덮어쓰기를 하지 않는다.
기존 메타데이터와 충돌하면 보완하지 않으며 세대·시세·등급·인쇄판을 추측하지 않는다.
현재 보완 대상은 기존 TCGdex 지원 지역의 포켓몬 카드다. 다른 제공처는 기존 결손 상태를 유지한다.

테스트는 페이지 재방문 없는 보완, 요청 상한, 재시작 대기·재시도, 동일 주기 중복 방지,
삭제·언어 충돌·변조 상태·실제 예산 경로 차단을 검증한다.
물리 태블릿 설치, 렌더, 속도 개선, 실제 신경망 학습을 검증했다는 문서가 아니다.
