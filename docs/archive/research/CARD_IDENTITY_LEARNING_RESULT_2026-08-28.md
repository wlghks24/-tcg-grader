# v109 카드명·카드번호 인식학습 결과

- Library 최근 이미지 처리본: 200장
- OCR 텍스트가 확보된 행: 164장
- 시각 검토 후 등록한 카드 기준자료: 21종
- 80% 이상 기준자료 후보가 검색된 행: 30장
- 검색된 서로 다른 카드 정체성: 19종

위 수치는 같은 Library 자료로 만든 기준사전의 **후보 검색 범위 검사**이며, 독립 시험사진으로 측정한 최종 정확도가 아니다. 따라서 30/164를 정확도라고 표시하지 않는다.

## 인식 순서

1. 앞면 카드 사진을 64비트 시각 특징값으로 변환한다.
2. 서버 사용 시 OCR을 두 방식으로 실행해 카드명과 카드번호 후보를 얻는다.
3. 카드번호 완전일치를 최우선으로 하고, 카드명 유사도와 선택 게임을 함께 비교한다.
4. 저장된 시세자료와 Library에서 시각 검토한 21종 참고사전에서 상위 5개 후보를 표시한다.
5. 사용자가 카드명·번호를 직접 확인하고 `인식 결과 확인·학습`을 눌러야 학습한다.
6. 같은 사진은 1회 확인 후 재인식할 수 있고, 촬영 조건이 다른 비슷한 사진은 같은 카드가 3회 이상 확인된 뒤에만 학습값을 사용한다.

## 안전규칙

- 자동 OCR 추정값은 자동 학습하지 않는다.
- 같은 이미지에 서로 다른 카드명이 확인되면 충돌자료로 격리하고 기존 값을 덮어쓰지 않는다.
- 카드명 학습과 등급 보정 학습을 분리한다.
- 슬랩 라벨은 카드명·번호 참고사전에만 사용하고 RAW 카드의 등급 보정값으로 사용하지 않는다.
- 서버가 없거나 OCR 구성요소가 없을 때도 기기에 저장된 사용자 확인형 시각학습은 사용할 수 있다.
