TCG-Grader-Sync 개인정보처리방침

최종 업데이트: 2026-09-19

1. 서비스 목적

TCG-Grader-Sync는 개인 사용자의 TCG 데이터를 Google Drive와 사용자가 관리하는 Android/Termux 태블릿 사이에서 동기화하기 위한 개인용 애플리케이션입니다.

2. Google 사용자 데이터 접근

TCG-Grader-Sync는 Google OAuth를 통해 Google Drive 접근 권한을 사용할 수 있습니다. OAuth 승인 범위는 Google Drive 전체 파일에 대한 접근을 포함할 수 있지만, 애플리케이션의 동기화 로직은 TCG_Grader_Sync 폴더와 관련 하위 동기화 경로를 대상으로 설계되어 있습니다.

3. Google 사용자 데이터 사용 목적

  • TCG 데이터 파일 확인 및 다운로드
  • 검증된 데이터의 태블릿 동기화
  • 동기화 성공/실패 receipt 업로드
  • 백업, 복구 및 무결성 검증
  • 동기화 오류 진단

Google 사용자 데이터는 위 기능 제공 목적 이외의 광고, 프로파일링 또는 판매 목적으로 사용하지 않습니다.

4. 데이터 저장 및 인증 정보

동기화 데이터는 사용자의 Google Drive 및 사용자가 직접 관리하는 Android/Termux 기기에 저장될 수 있습니다. OAuth 토큰 및 관련 인증 정보는 사용자의 기기 내 rclone 설정에 저장되며, 공개 GitHub 저장소나 공개 동기화 payload에 저장하지 않습니다.

5. 데이터 공유

TCG-Grader-Sync는 Google 사용자 데이터를 광고주에게 판매하거나 제3자에게 판매하지 않습니다. 사용자의 별도 요청 또는 법적 의무가 없는 한, 서비스 기능 제공과 무관한 제3자에게 Google 사용자 데이터를 공유하지 않습니다.

6. 데이터 보존 및 삭제

Google Drive에 저장된 동기화 데이터는 사용자가 직접 삭제할 때까지 유지될 수 있습니다. 사용자는 Google 계정의 연결된 앱/보안 설정에서 TCG-Grader-Sync의 OAuth 접근 권한을 언제든지 취소할 수 있으며, Android/Termux에 저장된 로컬 데이터와 rclone 설정도 사용자가 직접 삭제할 수 있습니다.

7. 보안

TCG-Grader-Sync는 허용 파일 제한, SHA-256 해시 검증, 스키마/무결성 검증, 백업 및 롤백 절차 등을 사용하여 동기화 데이터의 무결성을 보호하도록 설계되어 있습니다.

8. Google API Services User Data Policy

TCG-Grader-Sync의 Google API를 통해 수신한 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy(제한적 사용 요구사항 포함)를 준수하도록 운영됩니다.

9. 정책 변경

Google 사용자 데이터의 처리 방식 또는 서비스 기능이 변경되는 경우 본 개인정보처리방침을 업데이트할 수 있습니다.
