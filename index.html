PC 또는 안드로이드 태블릿에서 공식 페이지 변경 여부를 수집합니다. 승인 버튼은 검토기록을 저장하며 정적 BOX·카드 목록을 자동으로 덮어쓰지 않습니다.
서버 연결 대기 중
📱 앱 설치

아이폰 사파리에서 공유 → 홈 화면에 추가를 누르면 앱처럼 실행됩니다.

📟 안드로이드 태블릿 서버 설정 보기
  1. F-Droid에서 Termux와 Termux:Boot를 설치하고 두 앱을 한 번씩 엽니다.
  2. Termux에서 termux-setup-storage 실행 후 저장공간을 허용합니다.
  3. pkg update -y, pkg install python -y를 차례로 실행합니다.
  4. ZIP을 Download/TCG_GRADER에 풀고 cd ~/storage/downloads/TCG_GRADER로 이동합니다.
  5. bash START_TCG_UPDATER_ANDROID.sh를 실행하고 화면의 같은 Wi-Fi 접속 주소를 Chrome에서 엽니다.
  6. 자동실행은 bash ANDROID_AUTO_START_INSTALL.sh를 한 번 실행합니다.
  7. 설정 → 앱에서 Termux와 Termux:Boot의 배터리를 제한 없음으로 바꿉니다.
서버 사용 중에는 Termux를 종료하지 마세요. 공유기 포트를 외부 인터넷에 공개하지 말고 같은 Wi-Fi에서만 사용하세요.
