# TCG 등급 사전검사기 v31

Pokémon 및 ONE PIECE 카드의 사진을 이용해 센터링과 사진상 결함 위험을 사전 점검하는 한국어 PWA입니다. 결과는 정식 등급을 보장하지 않는 참고자료입니다.

## 추가된 통합 기능

- 앱 맨 위의 `신상품 · 사전예약 · 출시일` 카드에서 한국판·일본판·미국판·글로벌 공식 출시정보 확인
- 맨 위에서 `📅 출시일`과 `🎁 프로모 카드 행사`를 전환하고, 공식 확인된 행사 기간·경품·수령조건·수령기한 확인
- 2027년 여름 전 세계 동시 출시 예정인 `NARUTO CARD GAME` 사전 반영 및 공식 일정 자동 확인
- 출시일까지 남은 날짜를 D-day로 자동 계산하고 출시 당일/출시 완료 상태 표시
- GitHub Actions가 매일 공식 상품 페이지를 확인해 검증된 `releases.json`을 갱신
- 카드 등급 측정과 BOX 정보·시세를 큰 이모티콘 메뉴로 분리
- 흩어져 있던 자동 분석·디자인 분류·정밀 보더 측정·디자인 보정을 `🎴 카드 정밀 측정` 3단계 화면으로 통합
- 한국판·일본판·미국판 BOX 출고가, 현재 거래가, 원화 환산가 및 상승률 비교

자동 수집은 공식 출처에서 상품명과 출시일을 함께 확인할 수 있는 항목만 반영합니다. 사이트 응답 실패 시 기존 검증정보를 유지하며 실패 상태를 기록합니다.

최종 통합본에서는 누락 아이콘 참조와 화면 없는 과거 업데이트 코드를 제거했습니다. 검사 결과는 `FINAL_VERIFICATION_REPORT.json`에서 확인할 수 있습니다.

## 아이폰 단독 설치

1. 이 폴더의 `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `releases.json`, `promo_events.json`, `market_prices.json`, `exchange_rates.json`을 GitHub 저장소에 올립니다.
2. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/root`를 선택합니다.
3. 생성된 HTTPS 주소를 아이폰 Safari에서 엽니다.
4. Safari의 **공유 → 홈 화면에 추가 → 추가**를 누릅니다.
5. 한 번 온라인으로 실행한 뒤에는 핵심 화면을 오프라인에서도 열 수 있습니다.

주의: 아이폰에서 ZIP의 `index.html`을 파일 앱으로 직접 여는 방식은 PWA 설치와 오프라인 캐시가 정상 작동하지 않습니다. 반드시 HTTPS 웹주소로 여세요.

## PC에서 실행

- Windows: `START_TCG_UPDATER.bat` 더블클릭
- macOS: `START_TCG_UPDATER.command` 실행
- Python 3가 필요합니다.
- 실행창에 PC 주소와 같은 Wi-Fi의 아이폰 접속 주소가 함께 표시됩니다.
- Windows 방화벽이 물으면 **개인 네트워크**만 허용하세요.

## 레노버·안드로이드 태블릿에서 서버 실행

- F-Droid판 Termux와 Python을 사용합니다.
- `START_TCG_UPDATER_ANDROID.sh`를 실행하면 태블릿이 PC와 같은 서버 역할을 합니다.
- 자세한 최초 설치 방법은 `ANDROID_TABLET_SETUP.md`를 확인하세요.
- 같은 Wi-Fi에 연결된 휴대폰과 PC에서도 화면에 표시된 태블릿 주소로 접속할 수 있습니다.
- Termux의 배터리 사용을 **제한 없음**으로 설정하고, 서버 실행 중에는 Termux를 종료하지 마세요.

## 사용 순서

1. Pokémon 또는 ONE PIECE를 선택합니다.
2. 앞면·뒷면 정면 사진을 올립니다. 사선광 사진은 선택사항입니다.
3. `🎴 카드 정밀 측정`에서 자동 또는 수동 보정을 고릅니다.
4. `카드 자동 분석 시작`을 누릅니다.
5. 더 자세히 확인하려면 `정밀 교차검사`를 펼쳐 디자인 분류 → 권장 정밀 측정 → 보조 교차 측정 순서로 확인합니다.
6. 검출 신뢰도가 낮으면 단색 배경에서 다시 촬영합니다.
7. 실제 등급을 받은 뒤에만 교차검증 기록을 저장합니다. 최소 5건 전에는 자동 보정이 적용되지 않습니다.

## v31 수정사항

- 분석 버튼을 중단시키던 누락된 자동/수동 모드 요소 복구
- 화면 설명문 숫자가 실제 예측등급으로 저장되던 검증 오류 차단
- 계산된 최신 등급만 교차검증에 사용
- 누적 보정값을 다음 분석 결과에 실제 반영
- PC·안드로이드 태블릿 서버의 같은 Wi-Fi 휴대폰 접속 지원
- 시세·검증 항목을 직접 입력하지 않고 국가·게임·BOX/HIT 카테고리에서 선택
- PC·안드로이드 서버 실행 중 시작 직후 및 6시간마다 공식자료 변경사항 자동 확인
- v13 검색의 긴 표시문구와 내부 데이터 키가 어긋나던 오류 수정
- 검색 결과를 외부 시장 첫 화면이 아닌 앱 내부 카드로 표시하고, 선택 항목 시세 검색과 공식 상품정보를 별도 버튼으로 분리
- 공개 가격자료를 `market_prices.json`에 보존하고 `/api/market-price`로 앱 내부에 직접 표시
- PC·안드로이드 서버와 GitHub Actions에서 공개 가격자료를 주기적으로 갱신하며 실패 시 마지막 검증가격 유지
- v12·v13 모두 외부 사이트 이동 없이 가격 숫자·가격 성격·시장·거래자료·확인일을 표시
- BOX 결과에서 공식 출고가와 현재 거래시세를 같은 결과 카드에 분리 표시
- 프로모 카드 행사는 공식 출처가 확인된 자료만 표시하며 한국·일본·미국 국가 필터 제공
- BOX와 HIT 목록을 인기순위·최신 출시순·가나다순으로 전환하고, 선호도·출시일·검증 시세자료 갱신 시 인기순위를 다시 계산
- 한국판 OPK-01 로맨스 던 BOX의 KREAM 공개 구매가를 앱 내부에 표시하고, 판매완료 체결가와 구분
- 일본 엔화·미국 달러 공식가격 아래에 원화 환산금액과 환율 기준일을 표시하고, PC·태블릿·GitHub 자동 업데이트에서 참고환율 갱신
- 서버·페이지·캐시 버전을 v31로 통일
- 오래된 캐시 자동 삭제 및 PWA 아이콘 180/192/512 제공

## 한계
