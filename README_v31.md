# TCG 등급 사전검사기 v31

Pokémon 및 ONE PIECE 카드의 사진을 이용해 센터링과 사진상 결함 위험을 사전 점검하는 한국어 PWA입니다. 결과는 정식 등급을 보장하지 않는 참고자료입니다.

## 아이폰 단독 설치

1. 이 폴더의 `index.html`, `manifest.webmanifest`, `sw.js`, `icons` 폴더를 GitHub 저장소에 올립니다.
2. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/root`를 선택합니다.
3. 생성된 HTTPS 주소를 아이폰 Safari에서 엽니다.
4. Safari의 **공유 → 홈 화면에 추가 → 추가**를 누릅니다.
5. 한 번 온라인으로 실행한 뒤에는 핵심 화면을 오프라인에서도 열 수 있습니다.

주의: 아이폰에서 ZIP의 `index.html`을 파일 앱으로 직접 여는 방식은 PWA 설치와 오프라인 캐시가 정상 작동하지 않습니다. 반드시 HTTPS 웹주소로 여세요.

## PC에서 실행

- Windows: `START_TCG_UPDATER.bat` 더블클릭
- macOS: `START_TCG_UPDATER.command` 실행
- Python 3가 필요합니다.
- 실행창에 PC 주소와 같은 Wi-Fi의 아이폰 접속 주소가 함께 표시됩니다.
- Windows 방화벽이 물으면 **개인 네트워크**만 허용하세요.

## 사용 순서

1. Pokémon 또는 ONE PIECE를 선택합니다.
2. 앞면·뒷면 정면 사진을 올립니다. 사선광 사진은 선택사항입니다.
3. `자동 분석`을 누릅니다.
4. 검출 신뢰도가 낮으면 단색 배경에서 다시 촬영합니다.
5. 실제 등급을 받은 뒤에만 교차검증 기록을 저장합니다.
6. 최소 5건 전에는 자동 보정이 적용되지 않습니다.

## v31 수정사항

- 분석 버튼을 중단시키던 누락된 자동/수동 모드 요소 복구
- 화면 설명문 숫자가 실제 예측등급으로 저장되던 검증 오류 차단
- 계산된 최신 등급만 교차검증에 사용
- 누적 보정값을 다음 분석 결과에 실제 반영
- PC 서버의 같은 Wi-Fi 아이폰 접속 지원
- 서버·페이지·캐시 버전을 v31로 통일
- 오래된 캐시 자동 삭제 및 PWA 아이콘 180/192/512 제공

## 한계
