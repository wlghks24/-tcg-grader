- 전체 패키지 14개 Python 파일(AST) 파싱 검사: PASS.
- 정적 호출 목록 점검: 저장소로 자동 쓰는 기능 없음. `subprocess.run`은 Git의 읽기 전용 명령, 사용자가 명시적으로 선택한 Docker 검사에서만 사용. `eval/exec` 실행 없음. 내부 보고서용 파일 쓰기는 격리 출력 폴더로 제한.

- 미검증: 실제 Windows PC/Tkinter/예약 스케줄러, 전체 TCG 소스 clone에 대한 end-to-end, Docker 실기 회귀, 모든 역사 버전 원본, 태블릿 실기.

## 최종 패키지 두 번 독립 재검수

- 완성판 ZIP을 **서로 다른 2개 경로**에서 압축 해제 후 내부 `SHA256SUMS.json`으로 **25개 파일(콘텐츠 24개 + 매니페스트)** 검사: 두 환경 모두 PASS.
- **1차 독립 추출 `verification_A`: 60/60 테스트 PASS**.
- **2차 독립 추출 `verification_B`: 60/60 테스트 PASS**.
- 두 추출본 모두 *실제 CLI 진입점* `pc_auditor/audit.py --repo <임시Git> --latest 205 --output <외부폴더> --auto` 실행 PASS(보안상 HOLD 종료코드 2).
- 각 CLI 실행은 내부적으로 **1차 전체 실행 + 2차 독립 전체 실행**을 수행. 두 실행 간 보고서 17개가 정확히 같음을 별도 SHA-256 대조로 확인.
- 다른 추출본끼리의 수신 영수증도 완전 일치: `ff00dab40505e28258d848cd6dc7a9d505465bd7cb2a4b04b9513f174ec250f2`.
- V101–V200 체크포인트: 양쪽 모두 **생성 안 됨**. 원본 Git HEAD와 `git status --porcelain` 변화 없음.
- `double_review_receipt.json`: 실제 기능·역사 원본 근거 부족으로 `HOLD_DOUBLE_REVIEW_MATCHED_BUT_HISTORICAL_AND_FUNCTIONAL_EVIDENCE_UNVERIFIED`, 다음 구간 허가 `false`.
