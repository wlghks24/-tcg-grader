# 기존 태블릿 설치 폴더 패치

대상은 Lenovo 태블릿 Termux의 `$HOME/-tcg-grader`입니다. PC 이전이나 재설치가 아닙니다.

## 해결하는 문제

기존 업데이트는 main 브랜치의 fast-forward만 허용합니다. 운영 폴더가 cd7b40af 등의 커밋에 detached 상태로 고정되어 있거나 공식 main과 분기되면 자동 업데이트를 건너뜁니다. `ANDROID_RECOVER_UPDATE.sh`만 실행해도 이 상태는 해결되지 않습니다.

`execution/tablet_inplace_patch.py`는 명시적으로 지정한 공식 main의 전체 SHA와 일치할 때만 **동일 폴더의 코드**를 채택하고 main에 다시 연결합니다. 실행 전 계획이 기본값이며 `--apply`를 넣어야 파일을 변경합니다. main에 이미 연결된 저장소는 기존 보존 업데이트 도구를 사용합니다.

## 보존과 검증

- 기존 HEAD와 기존 main 커밋, staged 객체를 포함한 별도 index/worktree 보존 커밋은 별도의 `refs/tcg-recovery/inplace-*`로 보존합니다.
- 실제 교체 파일의 원본 바이트·권한, 원래 Git 인덱스, 적용 영수증은 태블릿 홈의 `tcg-inplace-patch-backups/inplace-*`에 보관합니다.
- 기존 `tablet_preserved_update.RUNTIME_PATHS`의 학습/시세/환율 JSON은 작업 사본을 교체하지 않습니다. 새 커밋의 JSON과 내용이 달라도 현장 자료를 유지합니다.
- 사진 등 미추적·무시 파일은 교체 대상이 아닙니다. 새 소스와 경로가 충돌하면 적용을 중단합니다. 상위 폴더의 심볼릭 링크와 알 수 없는 로컬 코드 변경도 중단 사유입니다.
- 예약 업데이트·서버 등 해당 폴더를 사용하는 프로세스가 실행 중이거나 프로세스 상태를 확인할 수 없으면 중단합니다. 임의 PID 종료는 하지 않습니다.
- 후보를 별도 임시 worktree에서 기존 `VERIFY_TABLET_FINAL.sh`로 먼저 검증합니다. 공식 main의 정확한 릴리스 SHA는 검토와 현재 커밋 CI 통과 후 선택해야 합니다. 이 도구는 GitHub CI 통과 여부를 대신 판정하지 않습니다.
- 기존 운영 폴더에서 읽기, 복사 재확인, 적용 전 재확인, 소스 blob 일치 확인, JSON 변화 확인 후에만 인덱스와 main 참조를 전환합니다.
- Git 인덱스 복구본은 소유자만 읽고 쓰는 0600 권한으로 복원하고, 코드 파일의 실행 권한은 유지합니다.
- 일반 예외·사용자 인터럽트는 원래 코드·권한·HEAD·인덱스를 복구합니다. 복구 자체 실패는 `MANUAL_RECOVERY_REQUIRED_KEEP_BACKUP`으로 보고합니다. 전원 차단/SIGKILL에 대한 자동 재개·자동 복구는 제공하지 않습니다. 영수증과 보존 폴더를 삭제하지 마세요.

## 태블릿에서 실행할 순서

1. GitHub에서 현재 패치 커밋의 CI와 main 반영 상태를 확인하고, main의 전체 SHA를 고정합니다. PR 브랜치 SHA를 main인 것처럼 전달하지 않습니다.
2. 검증된 릴리스에서 이 도구와 `tablet_preserved_update.py`를 같은 별도 임시 폴더에 준비합니다. 운영 소스를 먼저 덮어쓰지 않습니다. 부트스트랩 파일은 릴리스의 Git blob과 대조해야 합니다.
3. 예약 업데이트 및 수집 서버를 정상 종료하고 태블릿에서 실행 폴더를 확인합니다. 예약 스크립트의 `remove`는 부팅 등록도 제거하므로 패치 후 복원이 필요합니다. 기존 PID 14081을 재사용해 종료하지 않습니다.
4. 별도 폴더에서 `python tablet_inplace_patch.py --repo "$HOME/-tcg-grader" --expected-target 검증된_40자리_MAIN_SHA`로 계획을 읽습니다.
5. 같은 명령에 `--apply`를 추가해 코드 패치를 진행합니다. 성공 상태는 `PATCHED_SOURCE_ONLY`이며 앱 작동 확인을 의미하지 않습니다.
6. 성공 후 기존 서버 시작·실행 SHA 확인 도구를 사용하고 예약/부팅 등록을 복원합니다. 실제 카드 촬영, 등급 표시, HOT 카드/박스, 시세 원화 환산, 이벤트 화면은 태블릿에서 확인합니다.

## 현재 증거 범위

개발 검증은 임시 Git 저장소를 이용한 결정적 단위 시험입니다. 실제 태블릿 설치·서버 시작·카드 촬영·물리 장치 검증을 수행했다는 뜻은 아닙니다. 백업 파일의 무결성 확인만으로 복구 시험이 완료되었다고 기록하지 않습니다.

## V1015 보안 보완

GitHub Advanced Security의 별도 검사에서 발견한 두 경고를 보완합니다. 인덱스 복원 권한은 0600으로 제한하고 임시 파일도 처음부터 0600으로 생성합니다. WYYYES의 수집/카드 식별 API는 유지하며 CLI에는 고정된 상태값과 제한된 건수만 출력합니다. 원문 수집 결과, URL, 중첩 필드, 공급자 예외 문자열은 터미널 로그에 출력하지 않습니다. V1009의 과거 증거는 보존하고 두 변경 파일의 정확한 바이트·해시와 계보를 V1015 별도 후속 증거로 검증합니다.

## V1016 로그인 셸 판정 보완

현장 조회에서 발견된 `bash -l` 로그인 셸은 스크립트나 `-c` 명령이 없는 경우 기존 bare 셸과 같은 조건으로 처리합니다. 정확히 하나의 `-l` 또는 `--login`만 허용하며, 빈 추가 인자도 제거하지 않고 검사합니다. 스크립트·인라인 반복 명령·stdin 스크립트·sleep·실제 자식 Python 작업은 계속 적용 중단 사유입니다. 프로세스를 자동 종료하거나 터미널 세션을 닫는 기능을 추가하지 않습니다. V1015 증거와 인덱스 0600 권한·수집 CLI 개인정보 출력 차단 정책은 유지합니다.
