The delivery helper now recognizes either exact original START or reviewed wrapper realpath, still requiring two Bash arguments and the exact repository cwd before signalling. Missing/other-project/same-basename paths remain excluded. Bash readiness is checked before stopping the existing owner. After backup/source checks, the same strictly owned process is rechecked once immediately before handoff to handle a legacy supervisor restarting during the transition; unknown listeners still HOLD. Data JSON preservation/backups, normal detached switch, target-source self-attestation, collision protection and rollback are retained. Because the helper source changed, the tablet must bootstrap the exact target Git blob into an owner-private temporary file; the installed older helper intentionally refuses a different target helper source.
