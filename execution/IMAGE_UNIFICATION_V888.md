# V888 통합 사진·카드정보 보완 후보

## 확인한 원인과 수정

기존 V654 보완기는 set_code 또는 set_name이 있으면 카드번호 등이 비어 있어도 재확인하지 않는다. V888 repair_existing은 card_code, card_number, language, set_code를 확인하고 정확한 TCGdex 출처 ID로 누락 필드를 채운다. 기존 원본사진과 출처값은 덮어쓰지 않는다. 잘못된 ID·국가·충돌값·손상사진은 보완하지 않는다. 기존 수집기의 동일 Budget/state/thread-local 문맥이 필수이며 실행당 4건, 6시간 재시도 대기, 기존 403/429/요청·용량 예산을 따른다. 새 스케줄러를 만들지 않는다.

unified_feed는 정확한 코드·게임·국가·종류·언어·판본·세트 증거가 확인된 상품/사진을 한 항목으로 표시한다. 사진에서 확인된 정보도 catalog_overlay에 포함하고, 각 필드의 출처를 남긴다. 미확인 항목도 같은 목록에 표시하지만 이름 유사성만으로 합치지 않는다. 공개 market 자료에는 추정 정보를 쓰지 않는다.

압축은 해상도를 보존하며 WebP quality 60/70/80/90/95/100과 무손실 method=6 결과 중 검증을 통과한 가장 작은 파일을 선택한다. 손실 결과는 PSNR 38dB 이상 및 채널별 최대 오차 32 이하를 요구한다. 짧은 변 400px 미만/투명 사진은 무손실만 허용한다. 원본 파일을 변경하지 않는다. 픽셀 지표가 글자 판독을 보장하지 않으므로 사람/OCR 검증은 별도다. 공식 옵션 참고: https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#webp

## 로컬에서 사용할 수 있는 내보내기

```sh
python3 -m execution.tablet_image_unified_v888 --repo . --output /새로운/경로/통합카드.html
```

기존 Termux 사진 보관함의 실제 파일을 검증해 최대 60장/15MB를 자체 포함 HTML로 내보낸다. 국가와 게임 필터가 있고 외부 사진 요청이 없다. 기존 파일을 덮어쓰지 않는다. 이는 내보내기 화면이며 태블릿의 기존 홈 화면을 교체하지 않는다.

## 연결 상태

V887 read_live는 unified_catalog를 반환한다. repair_and_read는 기존 수집기 문맥을 받은 경우 실제 private index 보완 후 목록을 재생성한다. 보호된 V43/6시간 스케줄러 및 기존 태블릿 HTTP/UI에는 아직 연결되지 않았다. 해당 경로 적용은 정식 successor와 현재 HEAD CI, 실기 검증이 필요하다. 기기 설치·모델 학습·실제 사용자 사진 판독 시험은 수행하지 않았다.

## 검증

오프라인 실제 private index 저장/재조회, 세트만 있는 사진 복구, 잘못된 ID/충돌/재시도 지연, 기존 요청 예산 소진, 원본 불변, 통합 항목 중복·국가/판본 불일치 차단, HTML escaping, 압축 해상도/픽셀 보존을 테스트한다. 전용 기존 V887 CI에 새 테스트를 포함했다. 합성 흰 배경 글자 PNG의 압축 결과는 실제 카드 사진의 압축률로 일반화하지 않는다.
