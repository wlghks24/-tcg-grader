# V891 행사 커버리지 신선도 보완

기존 event_priority_watch._priority_gaps는 과거 공식 확인 행도 현재 커버리지로 계산한다. 새 시작 어댑터는 원래 game/region/topic/trust 계산 함수를 유지하면서 수집 시각이 7일 이내인 행만 전달한다. published_at이나 전체 파일 updated_at은 수집 증빙으로 사용하지 않는다. 날짜 있는 지난 행사는 최신 재수집됐더라도 현재 커버리지로 세지 않는다. KST 날짜를 적용한다.

원래 행사 스냅샷·아카이브·공식 신뢰 기준·수집 작업수/주기/네트워크 예산은 변경하지 않는다. 새 후보를 검증 완료로 만들지 않으며, 새 런처 main에서 기존 감시 루프가 시작되기 전에 연결한다. 실제 원본 모듈을 격리된 의존성으로 import하여 기존 반례/연결을 테스트했다.

신규 오프라인 9개 PASS: 오래된 자료의 잘못된 커버리지 재현, 7일 경계, 미래/불명/naive 시간, publication/file timestamp 대체 금지, 지난 일정, 원래 신뢰 조건, 입력 불변, 반복 연결, KST 자정, 실제 시작 함수 연결. 원본 모듈에서 필요한 신뢰/주제 설정과 실행 의존성만 격리했고, 조사 대상 함수 자체는 모킹하지 않았다.

작업 공간 초기화 후 GitHub exact HEAD에서 해당 원본 파일만 복구한 제한 복사본에서 검사했다. 이전 HEAD 6373c28의 GitHub 워크플로13개는 성공 확인. 새 HEAD의 전체 테스트·무결성·구조 검사는 GitHub에서 별도 확인해야 하며 로컬 전체 회귀를 수행했다고 주장하지 않는다. 태블릿 설치·자동부팅 변경·실기 실행·외부 자료 재수집·모델 학습은 하지 않았다.
