# V894 기존 기능 누락 방지 및 상세 화면 이동

새 UI는 대표 shortcut18개를 연결했지만, 원래 index의 고급·상세 section/details 전체에 대한 직접 이동 목록은 없었다. 현재 원본에서40구역과172개 button/input/select/textarea를 읽어 확인했다. 이는40독립기능이라는 뜻이 아니라 중첩 카테고리·결과·안내를 포함한 정적 화면 구역 수다.

/tablet-features는 원본 index를 읽어 전체 구역을 검색 가능한 목록으로 제공한다. 기존 새 UI/V881 메뉴에 이 목록 링크를 추가했다. ID가 없던 구역에는 HTTP 응답에만 안정적인 anchor를 추가한다. 기존 index/기능 소스는 수정하지 않는다. 기존 data-feature-key18개 메뉴도 그대로 유지한다.

/index.html?target=구역ID는 새 홈으로 돌아가 버리지 않고 원래 화면을 연다. 기존 TCGFeatureCategoryNav.openTarget을 통해 관리 화면과 상위 구역을 연다. 상세 안내만 펼칠 수 있으며 임의 버튼을 클릭하지 않는다. 측정 결과의 hidden/display:none는 강제로 해제하지 않는다. 아직 실행하지 않은 측정·결제·삭제를 화면이동으로 실행하지 않는다.

8개 로컬 검사 PASS: 현재 원본의 모든 구역/입력수와 target 보존, 응답 주석을 제거하면 원본 전체 bytes-equivalent 문자열이 복원되는지, 반복 주석의 동일성, 고급/무ID/안내 링크, ID중복/충돌, HTML escape, 결과숨김 보존, 안전한 파일읽기, 실제 Handler의 목록↔원본 target일치, FEATURE_BOOT JS문법. 런타임 검증은 격리 의존성의 실제 Handler를 호출했고 외부 연결은 없다.

현재 연결 가능한 정적 원본 기준의 이동 보완이다. 과거 모든 커밋에서 삭제된 기능/파일을 조사하여 복원했다는 증거는 아니다. 동적 생성 패널 전체와 실제 태블릿 클릭·배치는 실기에서 추가 확인해야 한다. 기본 main/기기설치/자동부팅/학습 변경은 하지 않았고 기존 명시적 새 런처에 연결했다. 원래 전체 화면은 view=classic으로 접근 가능하다.
