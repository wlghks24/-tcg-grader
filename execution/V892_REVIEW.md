# V892 통합 기록 및 누적 보완

## 실제 변경

이전 unified_feed는 화면 투영만 만들었고 동일 카드/BOX를 계속 보완하는 영구 기록이 없었다. 이제 private unified_entities_v892.json에 canonical ID, 사진/상품 식별자, 카드정보, 현재 출처, 보완 작업을 저장한다. 정확한 연결이 확인되면 기존 두 기록을 한 기록으로 합치고 기존 ID는 redirect로 보존한다. 이름 유사성으로 합치지 않는다.

수집 루프가 실제 보완·사진 수집을 마친 뒤 통합 기록을 갱신한다. 상태 조회는 저장/회차 누적 없이 투영한다. 새 UI도 같은 통합 기록을 투영하여 누적 정보와 필요한 작업을 함께 표시한다. 이전 관찰값이 누락됐다면 보존하지만 retained_fields 및 RECONFIRM_RETAINED_FIELDS로 표시한다. 같은 결과를 다시 읽거나 저장해도 현재 검증 사실로 승격하지 않는다. 카드번호·국가·언어·판본 충돌은 이전 파일을 보존하며 보류한다. 삭제된 사진은 과거 기록에서 되살리지 않는다.

## 연결된 작업

COLLECT_EXACT_IMAGE / ENRICH_EXACT_METADATA / VERIFY_EXACT_IDENTITY / RECONFIRM_RETAINED_FIELDS를 같은 기록에 붙인다. 기존 승인 제공처의 수집·보완 루프를 재사용하고 새 무제한 다운로더나 스케줄러를 만들지 않는다. 이 작업 목록을 붙였다고 모든 게임/제공처의 미확인 사진을 자동 해결한 것은 아니다. 정확한 ID/판본 자료가 없는 항목은 근거가 추가되어야 완성된다. 공개 market 원본을 추정값으로 덮어쓰지 않는다.

## 검증 범위

새 통합 기록 테스트12개 + 이전 신선도9개 = 로컬21개 PASS. 실제 저장/재조회/기록 합치기/redirect/정보 누적/재조회 승격 방지/동명이품 분리/식별 변경 보류/원본삭제/손상/상한/실제 수집 진입함수의 저장 및 실패 보존을 검증했다. 전체 저장소가 복구된 로컬 복사본은 아니므로 이전 UI/이미지 회귀는 GitHub 전용 CI에서 함께 확인해야 한다. 기기 설치·실기 카드 판독성·모델 학습·외부 재수집은 수행하지 않았다.
