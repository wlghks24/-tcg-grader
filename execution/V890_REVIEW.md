# V890 교차 검토 및 기능 보완

## 범위와 근거

이 변경은 V887~V889 통합 경로와 기존 행사·가격·등급·세대 모듈의 연결 경계를 검토했다. 저장소 전체의 모든 함수가 검증됐다는 뜻은 아니다. 기존 코드 자동 사전검토와 함께 행사, 카드가치, 이미지/보안의 세 독립 검토를 진행했고 공통 발견을 실제 코드·반례로 확인했다.

| 영역 | 확인한 문제 | 반영 내용 | 검증 |
|---|---|---|---|
| 수집 버튼 | default-src none CSP가 fetch 차단 | live만 connect-src self, 정적 내보내기는 none | live/standalone 정책 테스트 |
| 개인 자료 접근 | 새 Handler가 기존 Host 검사를 건너뜀 | 모든 새 GET도 기존 Host 검사 우선 | 거부 시 자료 조회·렌더링·fallback 0회 |
| 이미지 처리 | 15MB 초과에도 압축 계속 | 시도 상한 및 첫 용량 초과 후 추가 압축 중단 | 100개 입력, 기존100회 → 4회 시도/3장 포함 |
| 이미지 잠금 | 저장소 전역 잠금 안에서 인코딩 | 별도 압축 슬롯, 인코딩은 저장소 잠금 밖 | 압축 중 조회/삭제 가능, 삭제 후 캐시복원 금지, 동시요청 압축1회 |

| 등급·판매가 | 사진만으로 등급/가격 추정할 위험 | 기존 측정·정확 판본 거래 기능으로 연결 | 미측정/자료없음에서 값 생성 안 함 |

## UI

사진과 메타데이터를 한 타일로 구성했다. 국가·게임·카드/BOX·검색 필터, 연결상태, 카드번호/세트/세대/판본/언어/희귀도, 원본 확대와 출처, 행사 요약을 표시한다. 중국은 한 필터로 보되 간체/번체 식별값은 합치지 않는다. 기존 전체 기능 메뉴는 접어서 보존하고 언제든 열 수 있다. 모바일·태블릿에 맞춘 CSS 및 터치/키보드 초점을 제공한다. 렌더링된 실기 디자인 검증은 하지 않았다.

## 채점 방식

전체 코드 품질을 임의로 100점 환산하지 않는다. 이번 변경의 확인 기준 6개 중 자동 확인 5개 충족, 실기 1개 미확인이다(5/6). 기준: private index 실제 보완, 기존 메뉴 보존, Host/CSP 안전경계, 실제 JS 필터, 압축 동시성/상한, Lenovo 실기/판독성. 이는 이 변경의 검증 충족도이며 전체 프로젝트 완성도/등급 예측 정확도 점수가 아니다.

## 남은 과제

- 실제 사용자 카드 사진 판독성/세대 정확도/예상등급/판매가 성능은 검증하지 않았다. 공식 인증 RAW 사진과 정확한 판본 거래근거가 필요한 기존 조건은 유지한다.
- 기존 event_priority_watch._priority_gaps는 과거 검증 자료도 coverage로 계산한다. 이 역사적 감시 경로 수정은 정식 successor가 필요하며 이번 변경에서 고치지 않았다. 새 요약은 신선도와 역사자료를 분리한다.
- 확인한 행사 스냅샷의 공식 확인일이 오래돼 신선한 공식 확인 건수가 0이었다. UI 연결을 최신 자료 수집 성공으로 간주하지 않는다. 기존 공식 갱신 작업을 새 버튼에서 요청할 수 있다.
- 새 명시적 런처로 실행할 때 적용된다. 기존 main 시작 명령·자동부팅·태블릿 설치는 변경하지 않았다. main 직접 변경·자동 병합·모델 학습 없음.

V890 런처 기본 / 및 /index.html은 새 통합 UI를 연다. 기존 홈은 /index.html?view=classic, 기능별 기존 화면은 /index.html?feature=기존키로 유지한다. 기존 main 명령 자체를 바꾼 것은 아니다.
